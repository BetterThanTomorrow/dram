# Try Clojure in Calva

This is the “official” [https://github.com/clojure/try-clojure](https://tryclojure.org/) project with some VS Code settings to make it work nicely as a Calva quick start project.

For a starter project with Calva and Clojure **Getting Started** material, use the command **Calva: Create a Getting Started REPL project**.
